# itch.io devlog → Discord

Проверяет RSS-фид дев-логов твоей игры на itch.io раз в 15 минут и постит новые записи в Discord через webhook.

## Настройка

1. **Найди RSS-фид дев-логов.** Зайди на страницу дев-логов своей игры на itch.io
   (`https://itch.io/game/devlog/<твоя-игра>`) и найди внизу ссылку на RSS/XML-фид.

2. **Создай Discord webhook.**
   Настройки канала → Интеграции → Вебхуки → Новый вебхук → скопируй URL.

3. **Создай репозиторий на GitHub** (публичный или приватный — не важно) и залей туда эту папку целиком.

4. **Добавь секреты репозитория:**
   Settings → Secrets and variables → Actions → New repository secret
   - `FEED_URL` — ссылка на RSS-фид из шага 1
   - `DISCORD_WEBHOOK_URL` — ссылка из шага 2

5. **Готово.** Workflow сам запустится по расписанию (раз в 15 минут).
   Первый запуск ничего не постит — просто запоминает текущее последнее сообщение,
   чтобы не спамить весь архив дев-логов разом. Все дев-логи, опубликованные ПОСЛЕ
   первого запуска, будут прилетать в Discord.

   Можно также запустить вручную: вкладка Actions → Check itch.io devlog and post to Discord → Run workflow.

## Изменить частоту проверки

В `.github/workflows/check-devlog.yml` поменяй строку `cron: "*/15 * * * *"`.
Например `*/5 * * * *` — каждые 5 минут (учти, что GitHub Actions не гарантирует
точность расписания с интервалом меньше ~5 минут и может иногда задерживать запуск).
